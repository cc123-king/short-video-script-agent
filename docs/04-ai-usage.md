# AI 辅助、个人贡献与验证

这个项目里，我主要用 AI 帮我梳理需求、搭建代码结构，以及编写工具调用和异常处理的基础代码。遇到报错时，我会让 AI 辅助分析，再结合代码判断怎么修改，提示词也会根据生成效果继续调整。

我自己重点负责流程衔接，比如缺少目标时长时先追问，检索不到素材时调整查询或请求补充，脚本超时后修改并重新估算。同时，我会核对脚本和素材来源，避免模型编造产品信息。例如，P01 只说明“支持字幕”，就不能写成“效率提升 80%”。

验证时，我会检查正常生成、缺关键信息、无素材、工具失败和超时修正这几种情况，并保留脚本、工具返回值和修改记录。我还会改变目标时长或检查结果，确认 Agent 的后续动作确实随之调整。
