# 需求与成功标准

## 用户、问题与交付

用户是短视频创作者或营销运营。需要把产品素材组织成分镜、旁白/字幕和素材引用，满足指定时长，并能清楚知道风险、资料缺口与任务完成状态。

输入：主题、受众、平台、目标时长、风格、产品 ID，以及可选用户初稿。数据：带 ID、版本、事实及核准表达的合成素材，合成品牌规则。输出：标题、逐镜画面与文本、估算起止及总时长、来源引用、风险与状态。

本项目中的“轻剪演示版”是虚构产品，与招聘公司的真实产品无对应关系。只交付可编辑脚本和检查结果。

经作答者审阅确定：涉及具体界面的镜头先标记待确认，补充截图/录屏或界面说明后再细化；文本检查通过不代表具体 UI 已验证。待确认项逐镜输出。

## 成功标准与验收映射

| 标准 | 实现位置 | 验证 |
|---|---|---|
| 正常脚本含标题、分镜、旁白/字幕、时长、来源与状态 | `report.py`、`tools.py` | normal |
| 缺关键字段请求补充 | `domain.missing_fields`、模型决策 | missing |
| 无素材时改写查询或请求补充 | `search_materials`、模型决策 | no_material |
| 观察工具失败后决定下一步，不虚报成功 | Agent 观察循环、工具故障注入 | transient_failure、persistent_failure |
| 超时长时实际修改，再估算；否则明确失败 | 不可变脚本版本、`estimate_duration` | overtime、short_target、impossible_target |
| 产品事实有对应来源，违规后修正再检查 | 核准表达、`check_rules` | rule_repair、事实篡改测试 |
| 画面与标题不增加无依据产品能力，待确认标签不构成豁免 | 受控创作选项、同镜事实卡、`UNSUPPORTED_VISUAL` | visual_repair、画面与标题回归测试 |
| 至少两种由真实模型反馈产生的路径 | 千问原生 function calling、Trace | 真实运行记录，状态见评估文档 |
| 调用有界，到上限明确未完成 | `run_agent` | 上限单元测试与 CLI 命令 |

`target_seconds` 定义为最大时长；创作参考为上限的 80%–95%，不允许通过虚假总时长字段掩盖实际文本。平台、受众、风格影响模型的创作选择；平台名称不伪装成实时平台政策校验。

## 范围与非目标

优先交付 CLI、可替换资料、真实模型与离线入口、完整证据和测试。暂不实现视频渲染、真实 TTS、平台发布、UI、多 Agent、生产级向量数据库或跨进程恢复。

实际用时和未完成部分见复盘。没有将建议投入时间写成实际完成时间。
