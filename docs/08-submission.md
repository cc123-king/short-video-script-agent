## 提交步骤

1. 创建空 GitHub 仓库；默认建议私有。
2. 连接本地仓库并推送 `main`，以实际远端验证为准。
3. 私有仓库邀请指定评审账号并确认可读。
4. 执行 `git rev-parse HEAD`，提交题号 **4**、GitHub URL 和该最终 commit SHA。

最终 SHA 不写入其自身 commit 内容，避免自引用。压缩包是源码与验证材料的副本，不含 `.env` 或 `.git`，不能替代远端仓库可访问性的检查。
